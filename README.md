# Смена профессии

Веб-сервис, который помогает определить подходящие профессии на основе имеющихся навыков, понять, каких знаний не хватает, и найти направления для дальнейшего обучения.

**Демоверсия:** https://smena-professii.onrender.com/

## Возможности

- **Каталог навыков.** Навыки разделены на тематические группы: IT, финансы, дизайн, бизнес, коммуникации, сфера услуг, транспорт и другие.
- **Подбор профессий.** Сервис сопоставляет выбранные навыки с требованиями разных профессий и рассчитывает процент совпадения.
- **Анализ недостающих навыков.** Показывает, какие знания и умения необходимо освоить для выбранной профессии.
- **Рекомендации по обучению.** Предлагает образовательные программы и ссылки на подходящие курсы.
- **Поиск вакансий.** Получает вакансии через API HeadHunter. Также предусмотрена возможность подключения SuperJob.
- **Оценка зарплат.** Рассчитывает примерную среднюю зарплату на основе доступных данных о вакансиях.
- **История подборов.** Сохраняет последние результаты подбора профессий в браузере пользователя.

## Как работает подбор профессий

1. Пользователь выбирает навыки, которыми уже обладает.
2. Сервис сравнивает выбранные навыки с требованиями каждой профессии.
3. Каждому навыку присваивается вес от 1 до 3, определяющий его значимость для конкретной профессии.
4. На основе этих данных рассчитывается процент совпадения.

Формула расчёта:

```text
Совпадение (%) =
(Сумма весов имеющихся навыков /
Сумма весов всех навыков профессии) × 100
```

После расчёта профессии сортируются по степени совпадения. Пользователь получает список подходящих направлений, процент соответствия и перечень навыков, которые рекомендуется развить.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <ссылка-на-репозиторий>
cd <название-папки>
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

```bash
venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск приложения

```bash
python main.py
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000
```

## Переменные окружения

Для подбора профессий и рекомендаций по обучению дополнительные ключи не требуются.

Для получения вакансий предусмотрены следующие переменные окружения:

| Переменная | Назначение |
|---|---|
| `HH_TOKEN` | Токен приложения HeadHunter |
| `SJ_KEY` | Ключ API SuperJob |

Если ключи не настроены или внешний API недоступен, подбор профессий и рекомендации по обучению продолжают работать. Недоступным может оставаться только блок вакансий.

**Важно:** не публикуйте токены и ключи API в открытых репозиториях. Настраивайте их через переменные окружения на хостинге или локально.

## API

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/api/catalog` | Получение каталога навыков |
| POST | `/api/match` | Подбор подходящих профессий |
| POST | `/api/vacancies` | Получение вакансий по профессии |
| GET | `/api/history` | Получение истории подборов |

Документация API FastAPI доступна после запуска приложения:

```text
http://127.0.0.1:8000/docs
```

## База данных

Для хранения истории подборов используется SQLite.

В базе сохраняются:
- выбранные пользователем навыки;
- наиболее подходящая профессия;
- процент совпадения;
- дата и время подбора;
- идентификатор браузера.

База данных и необходимые таблицы создаются автоматически при запуске приложения.

## Развёртывание

Приложение можно развернуть на облачном хостинге, например Render.

Для запуска на сервере используется переменная `PORT`, которую предоставляет хостинг.

Переменные `HH_TOKEN` и `SJ_KEY` при необходимости настраиваются отдельно в параметрах окружения сервиса.
