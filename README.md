Смена профессии
Веб-сервис, который помогает подобрать профессиональные направления на
основе навыков пользователя, определить недостающие навыки и найти
варианты дальнейшего обучения.

Демо-версия: https://smena-professii.onrender.com/
Возможности
- Каталог навыков, разделённых на тематические группы.
- Подбор профессий с расчётом процента совпадения.
- Список уже имеющихся и недостающих навыков для каждой профессии.
- Рекомендации по обучению: ссылки на страницы Нетологии, поиск курсов
  Skillbox и общий поиск обучающих программ.
- Поиск вакансий через API HeadHunter.
- Резервный поиск через SuperJob, если настроен ключ API.
- Расчёт примерной медианной зарплаты по найденным вакансиям, в
  которых указана зарплата.
- История последних подборов. Записи хранятся в SQLite и связываются с
  анонимным идентификатором браузера.
Технологии
Серверная часть: Python, FastAPI, SQLite, HTTPX, Uvicorn, Pydantic.

Клиентская часть: HTML, CSS, JavaScript, LocalStorage.
Как работает подбор
Пользователь отмечает навыки, которыми обладает. Сервер сравнивает их с
требованиями каждой профессии. Навыки имеют вес от 1 до 3 в зависимости
от их значимости для профессии.

Процент совпадения рассчитывается по формуле:
Процент совпадения =
(сумма весов имеющихся навыков /
сумма весов всех навыков профессии) × 100
Результаты сортируются по проценту совпадения. В карточке профессии
отображаются совпавшие навыки, недостающие навыки и рекомендации по их
освоению.

Установка и запуск
1. Клонировать репозиторий
git clone <ссылка-на-репозиторий>
cd <папка-проекта>
2. Создать виртуальное окружение
python -m venv .venv
Активация в Windows:
.venv\Scripts\activate
3. Установить зависимости
pip install -r requirements.txt
4. Запустить приложение
python main.py
По умолчанию приложение запускается по адресу:
http://127.0.0.1:8000
Интерактивная документация API после запуска доступна по адресу:
http://127.0.0.1:8000/docs
Переменные окружения
Для подбора профессий и рекомендаций по обучению дополнительные ключи не
нужны.

Для получения вакансий предусмотрены переменные:

  Переменная   Назначение
  HH_TOKEN   Токен приложения HeadHunter
SJ_KEY     Ключ приложения SuperJob

Если HeadHunter недоступен или возвращает ошибку, приложение может
попробовать SuperJob, если задан SJ_KEY. Если оба источника недоступны
или ключи не настроены, подбор профессий продолжает работать, но данные
о вакансиях и зарплатах не отображаются.

Не добавляйте реальные токены и ключи в Git-репозиторий. Храните их в
переменных окружения.

База данных и история
Для хранения истории используется SQLite. При запуске приложения база
данных и таблица истории создаются автоматически, если их ещё нет.

История привязывается к анонимному идентификатору, который создаётся и
хранится в LocalStorage браузера. Это не система учётных записей:
отдельной регистрации пользователей в проекте нет.
Развёртывание
Проект развёрнут на Render. Для запуска на хостинге используется
переменная окружения PORT. Ключи HH_TOKEN и SJ_KEY, если они
необходимы, задаются в настройках окружения сервиса.
Примечания
- Каталог навыков, список профессий, веса навыков и рекомендации по
  обучению заданы в main.py.
- Ссылки на курсы являются рекомендациями для поиска обучения;
  доступность конкретных страниц и программ может меняться.
- Данные о вакансиях и зарплатах зависят от доступности внешних API.
