# Смена профессии

Веб-сервис для подбора подходящих профессий на основе навыков пользователя, анализа недостающих знаний и поиска направлений для дальнейшего обучения.

**Демонстрация:** https://smena-professii.onrender.com/

## Основные функции

- Каталог навыков, разделённых по тематическим категориям.
- Подбор профессий с расчётом процента совпадения.
- Анализ недостающих навыков.
- Рекомендации по образовательным курсам.
- Поиск вакансий через API HeadHunter и SuperJob.
- Примерная оценка заработной платы.
- Сохранение истории подборов.

## Используемые технологии

**Backend:** Python, FastAPI, SQLite, HTTPX, Uvicorn.

**Frontend:** HTML, CSS, JavaScript, LocalStorage.

## Алгоритм подбора профессий

Пользователь выбирает навыки, которыми обладает. Сервис сравнивает их с требованиями профессий и рассчитывает процент совпадения с учётом весов навыков.

Формула:

```text
Совпадение (%) =
(Сумма весов имеющихся навыков /
Сумма весов всех навыков профессии) * 100
```

## Установка

Клонирование репозитория:

```bash
git clone <ссылка-на-репозиторий>
cd <название-папки>
```

Создание виртуального окружения:

```bash
python -m venv venv
```

Активация в Windows:

```bash
venv\Scripts\activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск:

```bash
python main.py
```

После запуска приложение будет доступно по адресу:

http://127.0.0.1:8000

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `HH_TOKEN` | Токен HeadHunter |
| `SJ_KEY` | Ключ API SuperJob |

Для работы подбора профессий и рекомендаций по обучению эти ключи не требуются.

## API

| Метод | Маршрут | Описание |
|---|---|---|
| GET | `/api/catalog` | Каталог навыков |
| POST | `/api/match` | Подбор профессий |
| POST | `/api/vacancies` | Поиск вакансий |
| GET | `/api/history` | История подборов |

Документация API:

http://127.0.0.1:8000/docs

## База данных

Для хранения истории используется SQLite. База данных и необходимые таблицы создаются автоматически.

## Развёртывание

Проект размещён на Render. Для работы сервера используется переменная окружения `PORT`.
